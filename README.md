# student-dropout-insights

Mini Data Insight Dashboard: exploratory data analysis of student dropout risk.

## Dataset

[Student Academic Performance & Dropout Risk](https://www.kaggle.com/datasets/mohankrishnathalla/student-academic-performance-and-dropout-risk) (Kaggle): 100,000 students, 34 columns. Target: `dropout`.

Download `student_dropout_risk_2026.csv` from Kaggle and place it in `data/`.

## Key findings

- 32% of students dropped out. No missing values or duplicates.
- Low GPA and failed units are the strongest signals.
- Unpaid tuition, low family income and long work hours go with higher dropout.
- Gender, nationality and course type show no clear difference.
